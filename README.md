# VPM-Aufsichtseditor

Dies ist ein kleines Helferprogramm, mit dem der Pausenaufsichtsplan der Vertretungsplansoftware ABCsoft VPM über ein optisch ansprechendes UI bearbeitet werden kann. Benutzung auf eigene Gefahr, bei Fehlern gerne Issues - oder noch besser: Pull requests erstellen.

## Funktionen

* Anzeige des Plans sortiert nach Orten je Pause
* Auswahl der Pause per Dropdown
* Paste aus Excel-Tabellen möglich
* Reihenfolge der Orte per Drag-Drop änderbar
* Mehrere Aufsichten je Ort/Pause möglich
* Speichern der Daten in die VPM-Datenstruktur
* Prüfung auf Groß-/Kleinschreibung der Kürzel mit automatischer Abänderung bei Eindeutigkeit
* Prüfung auf Existenz eines eingegebenen oder gepasteten Kürzels

## Anforderungen

* Microsoft Windows 11
* Microsoft .NET 9 Framework
